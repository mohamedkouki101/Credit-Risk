# Learning path (PLAN §13 in full)

Ordered by when the roadmap needs each concept. Every resource with a link was opened during Phase 1 or Phase 2. Resources named without a link were **not** opened and are marked Unverified, so find them through the official site yourself. Do each self-check before starting the task it unlocks.

| # | Concept | Needed by | Primary resources | Self-check exercise |
|---|---|---|---|---|
| 1 | **Credit risk vocabulary: PD, LGD, EAD, EL; default definitions; vintages** | D-03 | [BCBS CRE36](https://www.bis.org/committees/bcbs/basel-framework/81373/chapter.pdf) (default definition, PD estimation, back-testing) · High. [EY on IFRS 9](https://ey.com/en_gl/ifrs-technical-resources/impairment-of-financial-instruments-under-ifrs-9) · Medium | Write half a page explaining why a charge-off target gives lower PDs than a 90-DPD target, and compute EL for a $10k loan at PD 8%, LGD 85%. |
| 2 | **Right-censoring and maturity in loan data** | D-03 | [Botha et al. 2026](https://arxiv.org/pdf/2603.11897), intro and data sections · High | Using a vintage table you build in D-03, explain why 2017 loans with status "Fully Paid / Charged Off" over-represent early outcomes. |
